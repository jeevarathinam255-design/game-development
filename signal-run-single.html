How this maps to real switch hardware: the SPACE key here stands in for a single external switch (jelly-bean switch, sip-puff, foot pedal, etc.) wired through a USB adapter or Bluetooth switch interface. Swapping the keydown listener below for a Gamepad API / WebHID event is the only change needed. Obstacles are shape- and label-coded (not color-only) for colorblind users. Screen reader users get status changes via the captions region (aria-live). This standalone build stores the leaderboard in your browser's localStorage instead of a backend server.
